# 越とは

## 越の基本

漢字の「越」は、空間や時間の境目を「こす・こえる」という意味を基本に、すぐれる、古い国名や地域名など、多方面にわたる豊かな意味を持っています。

### 基本的な意味と使い方

* こえる・こす：山や川、国境などの場所や、時間の経過、基準となる範囲を飛び越えること。例：越境、越権、越年。
* すぐれる・ぬきんでる：ほかより優れている状態。例：卓越、優越。
* 通り過ぎる・経過する：ある状態や時期をやり過ごす。
* 超越する：超 は 「高い・多い」方向にこえ、越は 「向こう側」へこえる。

### 漢字の成り立ちと語源

「越」という字は、「走（はしる・進む）」と「戉（えつ：大きな斧・まさかり）」という二つの要素から成り立っています。

* 「戉（まさかり）」の象形：古代中国において、大きな斧（戉）は王権や軍事力の象徴であり、神聖な武器とされていました。
* 「切り開く」から「越える」へ：もともとは斧で障害物を切り開きながら進むことを意味し、そこから「境界を通り過ぎる」「乗り越える」という意味へと発展したと考えられています。
* 霊的な力：斧が持つ霊的な力によって、困難や境界を突破していくという力強いニュアンスがその根源にあります。

### 画数および書き順

画数は12です。左側の「走」の部分は7画でそうにょう、右側の「戉」の部分は5画でえつ、またはまさかりです。

## 歴史・地理的な意味

### 中国・ベトナムにおける「越」

* 越国：春秋時代に存在した国名で、名君として知られる勾践（こうせん）が治めました。現在の浙江省周辺に位置します。
* 百越（ひゃくえつ）：古代中国の長江以南からベトナム北部にかけて居住していた諸民族の総称です。彼らは稲作や航海術に長けており、独自の文化を持っていました。
* ベトナムとの関わり：ベトナムの国名「越南（えつなん）」の「越」は、この百越の流れを汲む歴史に由来しています。

### 日本における「越（こし）」

* 越の国（こしのくに）：北陸道一帯の古称です。古くは「高志」や「古志」とも記されました。
* 名前の由来：都（奈良・京都）から見て、いくつもの険しい山々を「越えて」行く遠い地方であったことからその名がついたという説が有力です。
* 分割統治：大化の改新後、大和王権は強力な中央集権国家を目指しました。都から国司を派遣して統治させるには、広すぎる越の国を適切な広さに分割する必要がありました。これがのちに越前・越中・越後への分割につながりました。
* 越前 : 現在の福井県のおよそ北部・東部。
* 越中 : 現在の富山県。
* 越後 : 現在の新潟県の、佐渡島を除く本州部分。

## 言葉の持つニュアンスと印象

「越」という言葉は、現代の日本人にとって以下のような多層的な印象を与えます。

| 側面 | 与える印象・ニュアンス |
| :--- | :--- |
| 成長・向上 | 「限界を越える」「卓越する」といった、現状を打破して高いステージへ進むポジティブで力強い印象。 |
| 情緒・風土 | 日本の「越の国」のイメージから、雪国、静寂、粘り強さ、そこで育まれた豊かな文化や自然を感じさせます。 |
| 距離・旅情 | 「山越え」「国境を越える」など、遠く離れた場所へ移動する旅情や、未知の世界への広がりを感じさせます。 |
| 逸脱（注意点） | 「越権」や「越境」など、決められた枠組みやルールをはみ出すという、やや危ういニュアンスで使われることもあります。 |

## 名字や人名における意味

* 名字としての「越」：山や坂を越える場所、あるいは「越の国」にルーツを持つ地形由来の名字として、北陸や長野、関東地方に多く見られます。
* 人名（名付け）への願い：
    * 「困難を乗り越える強い人になってほしい」
    * 「周囲よりも卓越した才能を発揮してほしい」
    * 「枠にとらわれず、広い世界へ羽ばたいてほしい」
    といった願いを込めて用いられることが多い漢字です。

## 「越」がつく日本の地名

「越」のつく地名は、北陸地方（旧越の国）だけでなく、山越えや境界を意味する言葉として日本全国に存在します。

### 市区町村名
* 川越市（埼玉県）：入間川を「越える」地点であったことに由来するとされます。「小江戸」として知られる観光地です。
* 越谷市（埼玉県）：元荒川の「越（腰）」の部分にあたる低地、あるいは「越（こし）」の国からの移住者が開拓したなどの説があります。
* 越生町（埼玉県）：読みは「おごせ」。山を越えて行く「越し（おこし）」が転じたとされる難読地名です。

### 地域・町名
* 越路（新潟県長岡市）：旧越路町。北陸道の「越の国への路」を象徴する美しい地名です。
* 上越・中越・下越（新潟県）：旧越後国を都に近い順に分けた地域呼称です。
* 打越（全国各地）：横浜市、金沢市、京都市など各地にあり、山や丘を「打ち越える（越えていく）」場所を指します。
* 鳥越（全国各地）：台東区（東京）や金沢市など。鳥が越えていくほど険しい、あるいは神聖な場所といった意味が含まれることが多い地名です。

### 鉄道駅・路線名
* 羽越本線：出羽（山形・秋田）と越後（新潟）を結ぶ路線です。
* 信越本線：信濃（長野）と越後を結びます。
* 越後湯沢駅：川端康成の小説『雪国』の舞台として知られる駅です。
* 新越谷駅・南越谷駅：埼玉県の主要な乗換駅です。

### 難読地名・珍しい地名
* 神越（みのこし）：愛媛県八幡浜市。「神が山を越えた」などの伝承に由来する場合があります。
* 越代（こしだい）：福島県石川町。樹齢400年を超える「越代のサクラ」で有名です。
* 島越（しまこし）：岩手県田野畑村。三陸海岸に位置し、地形的な特徴を表しています。

## 難読字

* 越天楽（えてんらく） : 平安時代から伝わる日本の雅楽の代表的な曲名です。
* 越度（おちど） : あやまちや過失、手落ち、または法に反することを意味する言葉です。越度が変化して落ち度になったと言われています。
* 越階（おっかい） : 8世紀頃、当時の役人が、通常の順序や段階を飛び越えて、一気に上の位階に昇進することです。
* 越訴（おっそ） : 正規の法的手続きや管轄を無視（または飛び越えて）して、上級の機関や最高権力者に訴え出る行為のことです。直訴も越訴にあたります。
* 檀越（だんおち・だんおつ） : お寺や僧侶に対して金品を施し、経済的に支える信者や施主のことです。檀家の語源です。
* 夏越（なごし） : 毎年6月30日（または旧暦6月末）に行われる「夏越の祓（なごしのはらえ）」を指し、この半年の罪や穢れを祓い、残り半年の無病息災を祈る日本の伝統的な神事です。

## 時代劇における「越後屋」

時代劇で悪徳商人の代名詞として登場する「越後屋」ですが、その背景には実在のモデルと歴史的な経緯があります。

### 越後屋は越後（新潟）の商人？

最も有名な実在の越後屋（三井越後屋）は、越後出身ではなく伊勢（現在の三重県松阪市）の商人でした。

* 屋号の由来: 三井家の祖先である三井高安が、戦国時代に「越後守（えちごのかみ）」という受領名（官位の一種）を名乗っていたことに由来します。その後、三井高利が江戸に店を構える際、この先祖の通り名にちなんで「越後屋」という屋号を掲げました。
* 当時の状況: 江戸時代、伊勢商人の江戸進出は非常に盛んでした。「伊勢屋」という屋号が多すぎたため、差別化のために先祖ゆかりの「越後屋」を用いたとも言われています。

### 「悪徳商人」のイメージ

実在の越後屋は、むしろ「現金掛け値なし」という画期的な商法で庶民に愛された超一流の誠実な商人でした。それにもかかわらず、なぜ時代劇で悪役とされることが多いのでしょうか。

* 知名度の高さ: 江戸時代で最も有名な豪商であったため、視聴者が「商人といえば越後屋」とイメージしやすかったことが最大の理由です。
* 権力との繋がり: 豪商は幕府の公金を取り扱うなど、時の権力者（老中や勘定奉行など）と密接な関わりがありました。その構造が「代官と商人の癒着」という時代劇の定番の構図に当てはめやすかったと考えられます。
* 三越事件の影響: 昭和後期（1982年）に起きた「三越事件（当時の社長による不正事件）」が世間を騒がせ、その時期の時代劇で越後屋が悪役として定着したという説もあります。

「越後屋、お主も悪よのう」という定番の台詞は、特定の歴史的事実に基づくものではなく、誰もが知る大商人の名前を借りた劇中の創作から生まれたイメージと言えます。

## 受領名としての越後守

越後守とは、古代の律令制において日本の地方行政区分であった越後国の長官（国司の最上席）を指す官職名です。時代とともにその意味合いは変化していきました。

### 受領名（ずりょうめい）の仕組み

* 本来の意味: 平安時代以降、実際に現地に赴任して行政の全責任を負う国司を「受領」と呼ぶようになりました。越後守はその筆頭官職です。
* 武士のステータス: 鎌倉時代以降、武士が実力をつけると、朝廷から正式に任命されるだけでなく、幕府の許可を得て自称あるいは名誉職として名乗るケースが増えました。これが受領名としての名乗りです。
* 江戸時代の運用: 江戸時代になると、大名や旗本が幕府を通じて朝廷から叙任される正式な官職となりました。ただし、実際にその土地（越後）を統治しているかどうかは関係なく、家格や功績に応じて割り振られる一種のタイトル（肩書き）となっていました。

### 歴史上の著名な越後守

越後守を名乗った人物は、歴史上に数多く存在します。

| 人物名 | 時代 | 特徴 |
| :--- | :--- | :--- |
| 藤原 為時 | 平安時代 | 紫式部の父。越後守として実際に越後に赴任しました。 |
| 木曽 義仲 | 平安時代 | 平家を京都から追い落とした後、臨時に越後守を拝命。 |
| 上杉 謙信 | 戦国時代 | 「越後の虎」として知られる大名。正式な官位として越後守を叙任され、名実ともに越後の支配者として君臨しました。 |
| 三井 高安 | 戦国時代 | 三井家の遠祖。近江（滋賀県）の武士でしたが、織田信長に敗れ伊勢へ逃れました。越後守を自称し、後の屋号・越後屋の直接の由来となりました。 |
| 松平 光長 | 江戸時代 | 越後騒動で知られる越後高田藩主。徳川家康の曾孫にあたり、越後守を名乗りました。 |
| 水野 忠邦 | 江戸時代 | 老中として有名。一時期越後守を名乗りました。 | 

### 越後が選ばれた理由

越後国は律令制において「上国（じょうこく）」という高いランクに位置づけられていました。そのため、越後守という肩書きは、武士にとって誇らしく、権威を感じさせる響きを持っていたのです。この権威ある響きが、巡り巡って江戸時代の大商人の屋号となり、さらに現代の時代劇における「大物感のある商人」のイメージへと繋がっていきました。

## 越がつく歴史上の有名人

* 公孫越（こうそんえつ）：中国・後漢末期の武将。公孫瓚の弟として三国志に登場します。彼の死が袁紹戦争につながりました。
* 王越（おうえつ） : 中国・明代の武将。国防大臣級にまで昇進しました。詩文にも優れ、文武両道の代表格として広く知られました。

## その他

* パソコンの文字規格・Shift_JISでは、「越」の前2つは悦、謁。後2つは閲、榎。

# 越検定アプリ

## 目的

「越」に関する知識を楽しく確認できる、スマートフォン・PC対応の軽量なWebクイズアプリを作成する。

問題の知識源は、本Markdownの前半にある「越とは」の内容とする。ただし、アプリ実装時には「越とは」の内容から固定の四択問題をあらかじめ作成しておき、プレイ時にその中から10問をランダム出題する。

## 実装方針

### 構成

単一のHTMLファイルだけで動作する自己完結型とする。

- HTML
- CSS（HTML内の`<style>`）
- JavaScript（HTML内の`<script>`）
- 外部JavaScriptライブラリは使用しない。
- Web Audio API、Canvas API、Intl APIなど、ブラウザ標準APIは使用してよい。
- 日本語表示用フォントとしてGoogle Fontsの「Noto Serif JP」「Sawarabi Mincho」を`<link>`で読み込む。
- ローカルファイルとして開いても動作する構成にする。
- PCとモバイルの双方に対応する。

`index.html`、`style.css`、`script.js`の3ファイル構成にするとブラウザのセキュリティに抵触するため、すべてを記載した`index.html` 1ファイル構成とする。

## 問題データ

### 問題数

問題プールは**63問**。

1回のプレイでは、その中から10問をランダムに選ぶ。

### 問題形式

すべて四択問題とする。

問題データは次の形式でJavaScriptの配列に保持する。

```js
{
    q: "問題文",
    a: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
    c: 0
}
```

- `q`：問題文
- `a`：4つの選択肢
- `c`：正解選択肢の配列番号（0始まり）

問題プールの主な分野は以下。

- 基本的な意味と使い方
- 漢字の成り立ちと語源
- 画数および書き順
- 中国・ベトナムにおける「越」
- 日本における「越（こし）」
- 「越」が持つニュアンス
- 名字や人名における意味
- 「越」がつく日本の地名
- 鉄道駅・路線名
- 難読地名・珍しい地名
- 難読字
- 時代劇における「越後屋」
- 受領名としての越後守
- 「越」がつく歴史上の有名人

問題文・正解・選択肢は、前半の「越とは」に基づく固定データとする。

### 問題のランダム化

プレイ開始時に問題プール全体をシャッフルし、その先頭10問を今回の出題問題とする。

したがって、1回のプレイ中に同じ問題が重複して出題されない。

### 選択肢のランダム化

問題を表示するたびに、4つの選択肢の表示順もランダムに変更する。

正解判定は、表示順ではなく元データの正解情報に基づいて行う。

## 画面構成

画面はJavaScriptで動的に切り替える。

HTMLには以下を常設する。

- クイズ本体を表示する`#app`
- 画面最下部の進捗バー

### 1. タイトル画面

表示内容：

- 「越検定」
- etsu.gif
- 「あなたも検定に合格して「越」に入ろう」
- `START`ボタン

STARTを押すとクイズを開始する。

開始時に得点を0に戻し、問題番号を1問目に戻し、効果音用のAudioContextを初期化する。

### 2. 問題画面

画面上部から中央に問題文を大きく表示し、その下に4つの選択肢ボタンを表示する。

画面最下部には進捗バーを固定表示する。

進捗は、

- 1問目：10%
- 2問目：20%
- …
- 10問目：100%

となる。

文字は比較的大きくし、スマートフォンでもタップしやすいボタンサイズとする。

### 3. 正解時

選択した時点で回答を確定する。

すべての選択肢ボタンを無効化し、再回答できないようにする。

正解の場合：

- 得点を1加算
- 「正解！」を表示
- 正解用の効果音を鳴らす
- 墨が広がるような視覚効果を表示

さらに、一部の問題には正解後の補足解説を表示する。

以下の問題に解説を設定している。

- 越度と「落ち度」
- 戉と霊的な力
- 「越南」とVietnam
- 越後屋の「現金掛け値なし」
- 三越事件
- 松平光長と越後騒動
- 公孫越

解説がある問題では、

1. 選択肢を非表示
2. 「正解！」と解説を表示
3. 「次の問題へ ▶」ボタンを表示
4. ボタン押下で次の問題へ進む

解説がない問題では、「正解！」を表示した後、約2.5秒で自動的に次の問題へ進む。

### 4. 不正解時

不正解の場合：

- 得点は加算しない
- 「間違い！」を表示
- 不正解用のブザー音を鳴らす
- 朱印風の「×」アニメーションを表示
- 約1.2秒後に自動的に次の問題へ進む

不正解時には正解を表示しない。

### 5. 6問目で背景を変更

1プレイにつき1回、6問目の表示時に背景を変更する。

`body`に`bg-2`クラスを追加して背景色・背景表現を切り替える。

タイトル画面に戻ると`bg-2`を解除する。

## デザイン

全体として、日本の和紙・和風の検定証をイメージした落ち着いたデザインとする。

### 色

CSS変数を使用して、以下のような色を基調とする。

- 和紙系の明るい背景
- 濃い茶色の文字・アクセント
- 正解：緑系
- 不正解：赤系
- 朱色
- 金色

### フォント

本文は以下を優先する。

- Noto Serif JP
- Sawarabi Mincho
- Hiragino Mincho ProN
- Yu Mincho
- serif

### 背景

単色ではなく、以下を組み合わせた和紙風背景とする。

- 和紙色のベース
- SVGによる細かなノイズ
- radial-gradientによる薄い濃淡

画面端には、SVGを利用した和紙の切り口風の装飾枠を表示する。

### アニメーション

画面切り替え時には、`fade-in`によるフェード＋下からの移動アニメーションを使用する。

正解時には墨の広がり、不正解時には朱印風の×を一時的に画面上へ表示する。

## モバイル対応

画面幅600px以下では、モバイル向けに以下を調整する。

- タイトルを小さくする
- 問題文を小さくする
- メッセージを小さくする
- ボタンの文字・余白を小さくする
- コンテンツ領域を縦スクロール可能にする
- 合格証の幅を画面に合わせる
- 合格証の文字サイズ・装飾サイズを縮小する

## 進捗バー

画面最下部に高さ10px程度の進捗バーを表示する。

- 背景は薄い茶色
- 進捗部分は茶色系のグラデーション
- 進捗の右端に円形のアクセントを付ける
- 問題番号に応じて0～100%を滑らかに変更する

タイトル画面では0%に戻す。

## 音

BGMは使用しない。

効果音のみWeb Audio APIで生成する。

### 正解音

短い高音の「ピンポン」風。

- sine波
- 880Hzから1320Hzへ上昇
- 約0.5秒

### 不正解音

短いブザー風。

- sawtooth波
- 220Hzから110Hzへ下降
- 約0.3秒

音量設定画面やON/OFF設定は設けない。

## 結果画面

10問終了後に結果を表示する。

表示例：

`10問中 8問 正解！`

得点によって級を決定する。

| 正解数 | 級 | 合格証 |
|---:|---|---|
| 10 | 越検定1級 | 表示する |
| 8～9 | 越検定2級 | 表示する |
| 6～7 | 越検定3級 | 表示する |
| 4～5 | 越検定4級 | 表示する |
| 0～3 | 不合格 | 表示しない |

4級以上：

`越検定○級 合格！`

を表示し、「賞状表示」ボタンを表示する。

4級未満：

`残念でした。また挑戦してください。`

を表示する。

どちらの場合も「タイトルに戻る」ボタンを表示する。

## 合格証

4級以上の場合、賞状表示ボタンから合格証を表示する。

合格証は画面上にHTML/CSSで表示するだけでなく、Canvas APIでも画像化できるようにする。

### 合格証の画面表示

和風の賞状をイメージする。

- 和紙色の背景
- 金色の二重枠
- 四隅の装飾
- 「越」の朱印
- 「越検定 合格証」
- 合格した級
- 合格文
- 日付
- 「越検定協会」

合格文：

> あなたは「越」に関する深い知識を有し、本検定において優秀な成績を収めたことをここに証します。

日付は現在日付を取得し、`Intl.DateTimeFormat`の日本語・和暦カレンダーを使用して表示する。

対応していない環境では、西暦の年月日表示へフォールバックする。

### 合格証を閉じる

合格証はオーバーレイ上に表示する。

オーバーレイの合格証以外の部分をクリック／タップすると、

1. 合格証を閉じる
2. タイトル画面へ戻る

主要な状態変数：

```js
let currentQuestions = [];
let currentIdx = 0;
```

- `currentQuestions`：今回の10問

```js
const app = document.getElementById('app');
```

主要関数：

## 実装上の注意

- 1回のプレイでは必ず10問出題する。
- 問題プール内で同じ問題を重複させない。
- 選択肢は毎問シャッフルする。
- 選択後は再回答できないようにする。
- 問題終了後は結果画面へ遷移する。
- 結果画面からタイトル画面へ戻れる。
- 合格証を閉じた後もタイトル画面へ戻れる。
- AudioContextはユーザー操作後に初期化する。
- Canvas生成前にWebフォントの読み込み完了を待つ。
- 外部JavaScriptライブラリは使用しない。
- HTML/CSS/JavaScriptだけで完結させる。
- 問題データは外部APIやサーバーから取得しない。
- 固定問題データをJavaScript内に保持する。
- HTMLへ動的に挿入する文章には、問題データ上の信頼できる固定文字列だけを使用する。
- CSSやJavaScriptに不要な定義・変数・関数を残さない。
- 各主要セクション、主要関数、複雑な処理には、日本語コメントを適切に付ける。
- 仕様変更時には、既存機能を不用意に削除・変更しない。

# 文字「越」をGIFアニメにする方法

## KanjiVG.org を使用する

* https://kanjivg.tagaini.net/ にアクセス
* 「越」を検索し、SVGをダウンロードする
* 「越」は12画なので、SVGは12のパートに分かれている
* 「走」の横棒から始めて、「戉」の最後の点までの12のSVGファイルを作成する。

例として、最初の第一画目のSVGの一部を以下に示す。
```SVG:01.svg
<g id="kvg:08d8a" kvg:element="越">
	<g id="kvg:08d8a-g1" kvg:element="走" kvg:position="nyo" kvg:radical="general">
		<g id="kvg:08d8a-g2" kvg:element="土" kvg:position="top">
			<path id="kvg:08d8a-s1" kvg:type="㇐" d="M18.69,30.41c1.53,0.65,2.98,0.48,4.58,0.33c5.41-0.52,13.44-1.73,18.24-2.25c1.24-0.13,2.24-0.24,3.55-0.11"/>
		</g>
	</g>
</g>
```

## SVGをGIFに変換する

```Python:make_gif.py
# pip install cairosvg pillow

import cairosvg
from PIL import Image
import os

# 入力SVGファイル（01.svg ～ 12.svg）
frames = [f"{i:02}.svg" for i in range(1, 13)]
# 繰返しを考慮し、最後のフレームをさらに2フレーム追加する
frames.append("12.svg")
frames.append("12.svg")
print(frames)

# 一時PNG保存フォルダ
tmp_dir = "tmp_png"
os.makedirs(tmp_dir, exist_ok=True)

png_files = []

# SVG → PNG 変換
for svg in frames:
    png_path = os.path.join(tmp_dir, svg.replace(".svg", ".png"))
    cairosvg.svg2png(url=svg, write_to=png_path)
    png_files.append(png_path)

# PNG → GIF 生成
images = [Image.open(png) for png in png_files]

# GIFとして保存（ディレイはdurationパラメータで調整）
gif_file = "etsu.gif"
images[0].save(
    gif_file,
    save_all=True,
    append_images=images[1:],
    duration=250,   # 1フレーム250ms
    loop=0
)

print(f"GIF を {gif_file} として生成しました")
```
